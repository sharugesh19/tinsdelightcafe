# Gallery photos

Drop any `.png`, `.jpg`, `.jpeg`, `.webp`, or `.avif` image files directly into this
folder and they will automatically show up in the **Gallery** section on the
website — no code changes needed.

- File name becomes the photo's alt text (accessibility label), so name
  files descriptively, e.g. `cozy-corner-seating.jpg` or `filter-coffee-pour.jpg`.
- Any image size works; square-ish photos (close to 1:1) look best in the grid,
  but the grid crops gracefully either way.
- This file (`README.md`) is ignored by the gallery — only image files are picked up.
