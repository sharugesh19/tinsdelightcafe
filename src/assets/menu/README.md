# Menu item photos

Drop a photo in here named exactly after the menu item's `id` from
`src/config/menuData.js`, and it will automatically appear on that item's
menu card and (if the item is `featured`) in the Fan Favourites strip.

Examples, matching the sample data already in `menuData.js`:

- `pizza-margherita.jpg` → Margherita Pizza
- `bev-filter-coffee.jpg` → Filter Coffee
- `snack-chicken-65.jpg` → Chicken 65

Accepted extensions: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.

Items without a matching photo simply show a neat placeholder graphic — nothing
breaks if a photo is missing, so you can add real photos gradually.
